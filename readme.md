# Repagination - Marxism and Politics

A recreation of an important historical document.

## Description

The ***Repagination Project*** is an effort to recreate existing historical documents in order to make these more accessible to a wider public.

This particular document - *Marxism and Politics* - was only available publicly as either a scanned document where the text was extracted using Optical Character Recognition (OCR), or as a plain text file. These versions of the book lack accessibility features, and OCR text generated artifacts and errors, which makes it more difficult for many to consume these documents.

The ***Repagination Project***'s goal is to correct these flaws, and create an improved document, accessible to the widest possible audience. 

## Text Corrections

Errors are common in the Optical Character Recognition (OCR) process. It is no surprise the original OCR'd *Marxism and Politics* documents contain errors and artifacts.

Contributors are encouraged to file pull requests in order to correct spelling errors, or grammatical errors.

A non-exhaustive list of correction examples:
    * a space is often inserted between the end of a word and a closing single quote;
    * missing characters - when characters are missing from the text:
        * opening or closing brackets, or quotes;
        * empty spaces where an alpha-nemeric or punctuation character should be.
    * character substitutions - when one character is expected, but another is found in the text:
        * instead of capital S character, the number 5 character is found.
